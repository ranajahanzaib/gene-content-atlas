SCIENTIFIC TRANSPARENCY DATA NOTES

Methods & provenance

Know where each value comes from, and where this exploration build stops.

01 / DATASET

Deterministic synthetic fixture

Dataset ID demo-lp-v1, seed 20261122. Strain names, family membership, copy counts and coordinate offsets are generated for UI demonstration. The species label provides context only; records are not real isolates.

No real genomic data loaded
02 / CLASSIFICATION

Family prevalence

Prevalence is the number of distinct genomes with a family divided by the number of genomes in the selected cohort. Core means present in all genomes; accessory uses a 15% frequency floor; singleton means one genome.

Computed from fixture membership
03 / NOT IMPLEMENTED

Real analysis pipeline

NCBI acquisition, annotation parsing, Panaroo clustering, phylogenetic inference and sequence-based synteny are not available in this build. No evolutionary tree or biological relationship is claimed.

Unavailable in this build
04 / REPRODUCIBILITY

API and export

Local JSON is generated on first start. The API exposes dataset summary, matrix and family views. TSV export preserves integer copy counts with zero for absent families; prevalence is a fraction in [0, 1].

Check local API ↗
INTERPRETATION NOTE

Illustrations are not observations

The demo is useful for exploring interaction patterns and the data model. Its synthetic membership patterns, coordinates and source labels must not be cited or interpreted as findings about L. plantarum.
