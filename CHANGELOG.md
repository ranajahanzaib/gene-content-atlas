# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Local comparative genomics dashboard with family matrix, strain comparison, gene-content clustering, statistics, and exports.
- NCBI RefSeq acquisition and Panaroo analysis with input validation and provenance records.
- Documentation for the API, data model, methodology, ingestion, visualization, and deployment limits.

### Changed

- Demo and real-data views identify their data source and avoid presenting gene-content clustering as sequence phylogeny.
